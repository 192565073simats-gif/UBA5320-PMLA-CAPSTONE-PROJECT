About This Project

Statistical Analysis of Student Academic Performance Using Probability Distributions

This application analyzes student academic marks using statistical methods and probability distributions to help educators understand academic performance, identify students who may need additional academic support, and generate meaningful statistical reports.

Project Modules
Module 1: Data Collection
  • Student and subject management
  • Marks entry and CSV/Excel upload
  • Data validation and duplicate detection
  • Missing value handling
Module 2: Statistical Analysis
  • Descriptive statistics (Mean, Median, Mode, Variance, SD)
  • Normal distribution fitting and testing
  • Binomial pass/fail analysis
  • Interactive Plotly visualizations
Module 3: Performance Evaluation
  • Student performance categorization
  • At-risk student identification (z-score based)
  • Subject-wise comparison and ranking
  • PDF and CSV report generation
Statistical Methods
Descriptive Statistics
  • Mean — Average student marks
  • Median — Middle value of arranged marks
  • Mode — Most frequently occurring mark
  • Range — Difference between highest and lowest
  • Variance — Measure of data variation
  • Standard Deviation — Spread from the mean
  • Skewness & Kurtosis — Shape of the distribution
Probability Distributions
  • Normality Testing — Shapiro-Wilk / D'Agostino-Pearson
  • Normal Distribution Fitting — MLE parameter estimation
  • Binomial Distribution — Pass/Fail probability model
  • Z-Score Analysis — Relative standing of students
  • IQR Outlier Detection — Identify unusual values
